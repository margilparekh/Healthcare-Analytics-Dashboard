# Healthcare-Analytics-Dashboard
Developed an interactive Healthcare Analytics Dashboard using Power BI to analyze patient data, track hospital performance, and visualize key healthcare KPIs. Used data cleaning, Power Query, DAX, and interactive visualizations to transform raw data into meaningful insights for better decision-making.

Developed an interactive Healthcare Analytics Dashboard using Microsoft Power BI to analyze hospital operations, patient information, and key healthcare performance indicators. The dashboard transforms raw healthcare data into meaningful insights to support data-driven decision-making and improve operational visibility.

**Key Features**
KPI Tracking: Visualized important healthcare metrics and operational performance indicators.
Patient Analytics: Analyzed patient-related data to identify trends and patterns.
Interactive Visualizations: Created dynamic charts, graphs, and filters for exploring healthcare data.
Drill-Through Analysis: Enabled detailed exploration of specific healthcare metrics.
Performance Monitoring: Presented key insights through an organized and user-friendly dashboard.

**Tools & Technologies**
Microsoft Power BI
Power Query
Data Cleaning & Transformation
Data Visualization
Exploratory Data Analysis (EDA)
DAX

**Project Objective**
The main objective was to demonstrate how business intelligence and data visualization can help healthcare organizations monitor performance, understand patient trends, and make informed operational decisions.

Power BI | Data Analytics | Dashboard Development | Data Cleaning | KPI Reporting | Business Intelligence
